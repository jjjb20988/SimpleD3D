Keybinds:\
ARROW KEYS / RIGHT CLICK to rotate camera.\
WASD to move, E and Q to go up and down.\
T to teleport\
N to create a part\
M to delete a part\
C to edit a part\
F is to import external mods\
I to add a texture (hex codes count too! (ex: #FFFFFF)) (Text can also be made (ex:\
text:Hello world! font:bold 32px sans-serif color:FFFFFF) do not include the # in the color part for text)\
K to delete a texture\
P to preform a preformance test (50 is usually the maximum parts i reccomend for slow computers)\
V to view a texture\
R to load the preset room\
L to do a test raycast\
B to Deselect a part.\
G to select a part\
U to hide the UI\
Y to show this menu\
R to load in the PRESET room\
X to SAVE\
Z to LOAD\
J is to create a new part at the cameras current position\
SPACEBAR to reset the camera position\
0 is to view the warnings\
1 is to show external mods\
